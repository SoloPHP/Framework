# Framework

> [!WARNING]
> **Abandoned.** This metapackage is no longer maintained, and its version constraints predate the current Solo packages. Start a new project from [solophp/skeleton](https://github.com/SoloPHP/Skeleton) instead:
>
> ```bash
> composer create-project solophp/skeleton my-app
> ```

Solo is a set of small, independent PSR packages. Require the ones your application needs, or begin with the skeleton, which wires them together into a working application. See [github.com/SoloPHP](https://github.com/SoloPHP).
